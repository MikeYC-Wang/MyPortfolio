用 Apache ECharts 打造賽博龐克風的發光漸層圖表～

大家平常在刻後台系統的時候，是不是常常覺得儀表板上的折線圖有夠無聊？通常就是白底配上幾條乾癟的細線，看了就想打瞌睡。

但其實只要動點手腳，把死氣沉沉的 CPU / RAM 監控數據，加上一點 「漸層」 跟 「發光」 特效，整個系統的質感瞬間就會飆升到另一個次元！今天就來分享，我是如何利用 Apache ECharts 的進階屬性 LinearGradient，畫出帶有 Cyberpunk 科技感的動態儀表板。

💡 核心秘訣：拆解「科技感」的兩大元素

要做出那種「駭客感」的圖表，其實只需要掌握兩個 ECharts 的隱藏殺手鐧：

  1. 霓虹發光線條：利用 shadowBlur 讓折線自帶光暈。
  2. 漸層半透明底部：利用 echarts.graphic.LinearGradient 讓折線下方填滿漸層色。

🛠️ 實戰教學：設定 Option 參數

這裡我直接附上 Vue 3 + ECharts 的 Option。我們以 CPU 使用率 為例，主色調選用極具賽博龐克風味的螢光青色 (#00f2ff)。


      

        
        
// 記得先 import echarts
import * as echarts from 'echarts';

const option = {
  // 1. 背景一定要透明或深色，光暈才出得來
  backgroundColor: 'transparent',
  
  // X 軸與 Y 軸的基礎設定 (把格線調暗)
  xAxis: {
    type: 'category',
    data: ['10:00', '10:01', '10:02', '10:03', '10:04'],
    axisLine: { lineStyle: { color: '#00f2ff' } }
  },
  yAxis: {
    type: 'value',
    splitLine: { lineStyle: { color: 'rgba(255, 255, 255, 0.05)', type: 'dashed' } }
  },
  
  // 2. 這裡才是魔法發生的地方
  series: [
    {
      name: 'CPU Usage',
      type: 'line',
      data: [12, 45, 80, 42, 33],
      smooth: true, // 讓線條變成平滑曲線
      symbol: 'none', // 隱藏折線上的小圓點，看起來更洗鍊
      
      // 秘訣一：折線本體的發光效果
      lineStyle: {
        width: 3,
        color: '#00f2ff',
        shadowColor: 'rgba(0, 242, 255, 0.6)', // 光暈顏色
        shadowBlur: 15,  // 光暈擴散程度
        shadowOffsetY: 5 // 光暈稍微往下偏移，立體感++
      },
      
      // 秘訣二：下方的半透明漸層填色
      areaStyle: {
        color: new echarts.graphic.LinearGradient(0, 0, 0, 1, [
          {
            offset: 0,
            color: 'rgba(0, 242, 255, 0.5)' // 頂部較濃
          },
          {
            offset: 1,
            color: 'rgba(0, 242, 255, 0.02)' // 底部幾乎透明
          }
        ])
      }
    }
  ]
};

🍻 結尾

老實說，搞這些發光特效不是為了顯擺，單純就是不想每天盯著白底黑字的圖表懷疑人生。寫程式、管系統已經夠燒腦了，把監控台弄得帥一點，維修起來也比較有動力（這大概就是工程師的浪漫吧？）。

反正 Option 參數調一調也花不到幾分鐘。與其看著那幾根乾癟的細線，不如直接讓它帥一波。這招學起來，下次演示專案或是主管盯進度時，這張發光的圖表說不定能幫你擋掉不少麻煩（笑）。
